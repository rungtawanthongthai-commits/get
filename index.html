📋 รายงานขั้นตอนการใช้ AI ในการพัฒนา Platform

ตามข้อกำหนดโปรเจกต์ที่อนุญาตให้ใช้ AI ช่วยทำ platform ได้ รายละเอียดการใช้งาน AI ในแต่ละขั้นตอนมีดังนี้:

1. วางแผนและวิเคราะห์ปัญหา

ใช้ AI ช่วยวิเคราะห์พฤติกรรมการทิ้งขยะพลาสติกในสังคม และจำแนกประเภทสีถังขยะตามมาตรฐานสิ่งแวดล้อม

2. ออกแบบโครงสร้างและ UI

ใช้ AI ช่วยเจนเนอเรทแนวคิดการออกแบบเว็บ (UI Component Design) และจัดธีมสีของถังขยะให้เข้าใจง่าย

3. พัฒนาโค้ดและระบบค้นหา

ใช้ AI เขียนโค้ดระบบสืบค้นประเภทขยะและ logic มินิเกมคัดแยกขยะด้วย JavaScript และ Tailwind CSS
